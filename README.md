# 🧸 Cozy Bot

A Discord bot that records the final Top Cozy result from Mix It Up.

## Features

- 🧸 Records Top Cozy winners
- 💜 Saves Cozy percentage
- 📅 Saves the stream date
- 🏆 Tracks total Top Cozy wins
- ☕ `!mycozy` shows Cozy history
- 🔄 Prevents duplicate results
- 🌐 Receives final Cozy results from Mix It Up
- 💾 Database-backed history

## Important

The existing Mix It Up Cozy command is not modified.

A separate Mix It Up action sends the final result to the Cozy Bot.
